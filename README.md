# config-opencode

Private global OpenCode configuration repo.

Contains `house-*` commands, global skills, agents, plugins, and OpenSpec
docs/specs shared across projects on this machine.

Secrets and machine-local state (accounts, logs, caches, temp files) are
intentionally excluded via `.gitignore`.

The global house-style schema itself lives in the separate
[`house-style-sdd`](~/.local/share/openspec/schemas/house-style) repo.
